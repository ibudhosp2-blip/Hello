# Bathroom Slip Trap

เกม CSI แบบ point-and-click ห้องเดียว: สำรวจห้องน้ำจากภาพสแกน LiDAR, ตรวจศพ, เก็บวัตถุพยาน 5 จุด แล้วสรุปคดี

- เปิด `index.html` ในเบราว์เซอร์ได้เลย (โหลด three.js r128 จาก cdnjs)
- ลากนิ้วเพื่อหมุนรอบห้อง, ถ่าง/ลากสองนิ้วเพื่อซูมและเลื่อน
- แตะสองครั้งที่วงสีส้มเพื่อซูมเข้าไปดูภาพเสมือนจริงของจุดนั้น

# Toommeng888 Roulette (`toommeng888/`)

รูเล็ทยุโรป (0–36) แบบชิปปลอม ไว้เล่นขำๆ กับเพื่อนบนมือถือเครื่องเดียว — ไม่มีเงินจริง

- เปิด `toommeng888/index.html` ได้เลย ไม่ต้อง build
- กด `+ เพื่อน` เพื่อเพิ่มผู้เล่น (เริ่มคนละ 1,000 ชิป) แตะชื่อเพื่อสลับคนวาง แตะชื่อคนที่เลือกอยู่เพื่อเปลี่ยนชื่อ/เติมชิป/ลบ
- ทุกคนวางเสร็จแล้วกด `หมุน!` ครั้งเดียว ระบบจ่ายตามกติกา: เลขเดี่ยว 35:1, โหล/แถว 2:1, แดง-ดำ/คู่-คี่/สูง-ต่ำ 1:1 (ออก 0 เสียเดิมพันนอก)
- ยอดชิปและผลย้อนหลังเก็บไว้ในเบราว์เซอร์ (localStorage)
